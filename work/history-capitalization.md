# History capitalization handoff

Goal: preserve a learned phrase's spelling when unrelated writing later uses the same word with different casing.

Completed: `TypingHistoryPhrasePredictor` keeps case-insensitive vocabulary/context IDs for confidence and lookup, and retains one `Continuation(count, spellingID)` per context/next-token candidate. Exact spellings are interned once in `displayForms`; each transition selects the latest spelling actually observed after its own context. Both three-token and two-token fallback tables use this rule. Unrelated lowercase words no longer rewrite an earlier uppercase phrase. Confidence thresholds, partial-word filtering, whitespace and output budgets are unchanged.

Memory boundary: final storage grows with distinct exact spellings and retained transitions, rather than record occurrences. Transition values are 8 bytes instead of 4. Build-only sequences now retain one 4-byte spelling ID per token, matching the old sequence width. A separate 4-byte-per-distinct-spelling map resolves folded vocabulary IDs during table construction and is then released, alongside the spelling interning dictionary. No per-transition String or casing-frequency dictionary is retained.

Measured deterministic occupied-slot representation: a corpus with six uppercase phrase records plus six lowercase unrelated records retains 20 transition candidates and three extra case variants. Prior representation: 256 bytes; current: 384 bytes; increase: 128 bytes (20 * 4 + 3 * 16). Repeating that corpus 100 times still gives 256/384 bytes. These numbers count occupied spelling array slots and transition values only; exclude dictionary keys/capacity and String heap allocation. They are not RSS/total heap estimates.

Verification: exact production predictor source compiled and ran in a standalone Swift harness with a minimal record value; uppercase prediction and 100x corpus storage stability assertions passed. `git diff --check` passes. No Xcode builds, model runtime, shared DerivedData, or application runtime invoked. Parent owns full app test execution.
